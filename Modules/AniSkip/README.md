# AniSkip

Метки заставки, титров и рекапа из [AniSkip](https://api.aniskip.com) для любого онлайн-провайдера. Формат ответа тот же, что у `SegmentTpl` (`{"ad":[],"skip":[{"start","end"}]}`), который Lampa уже понимает у Kodik, Aladin и Alloha.

## HTTP

| Маршрут | Параметры | Описание |
|---------|-----------|----------|
| `GET aniskip` | `title`, `year`, `e` (номер серии) | MAL ID берётся через поиск Shikimori (`shikimori.io`, id Shikimori == MAL id). |
| `GET aniskip` | `mal_id`, `e` | То же без поиска, для отладки. |

Ответ `{}` значит «меток нет» (кэшируется 12 часов). Сбой сети даёт `503` и не кэшируется.

## Клиент

`Online/plugin.js` перед воспроизведением (`loadSegments`) запрашивает метки, если карточка японская аниме (`original_language = ja`, жанр «Анимация»), сезон 1 и у провайдера нет своих меток.

## Ограничения

- Только 1 сезон: у AniSkip нумерация серий внутри записи MAL, пересчёта TMDB-сезонов нет.
- Метки приходят от разных рипов (`episodeLength=0`), возможен сдвиг на секунды.
- Метки получает только текущая серия, не плейлист.
- Поиск по названию нечёткий; при неверном совпадении отладьте через `mal_id`.
- Нет настроек в `init.conf`.
